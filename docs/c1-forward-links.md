# C1 forward links

A C1 lesson that links to a lesson that isn't written yet uses plain text instead of a LessonLink or a `related` entry. Each such link is listed here. When the target is written, restore the link and remove its row. `npm run check:c1-links` fails on a LessonLink or `related` entry to a missing lesson. It also fails on a row below whose target now exists.
