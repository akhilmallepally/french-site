# C2 forward links

A C2 lesson that links to a lesson that isn't written yet uses plain text instead of a LessonLink or a `related` entry. Each such link is listed here. When the target is written, restore the link and remove its row. `npm run check:c2-links` fails on a LessonLink or `related` entry to a missing lesson. It also fails on a row below whose target now exists.

Restored in Prompt 43: c2-review-form → c2-paronyms (What's next).
